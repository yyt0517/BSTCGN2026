# BSTGCN 训练脚本修改 (2025-11-20)

## 📋 修改概述

针对您提出的两个问题进行了修改：

1. ✅ **早停策略过于严格** → 增加patience从25到40
2. ✅ **结果被覆盖** → 使用时间戳创建独立目录

---

## 🔧 具体修改

### 修改1：早停策略调整

**文件：** `scripts/BSTGCN/train_bstgcn.py` (第294行)

**修改前：**
```python
'patience': 25,  # 增加早停耐心 (从15到25)，允许更多验证波动
```

**修改后：**
```python
'patience': 40,  # 增加早停耐心 (从25到40)，允许更长时间探索
```

**原因分析：**
- 从您的训练日志看，模型在Epoch 63达到最佳Val F1 (0.9004)
- 在Epoch 88触发早停（patience=25）
- 您提到非贝叶斯版本需要100+轮才达到最佳Train F1
- 贝叶斯模型的验证F1波动较大（MC采样的随机性）
- 增加patience可以给模型更多时间探索，可能找到更好的解

---

### 修改2：结果保存方式改进

**文件：** `scripts/BSTGCN/train_bstgcn.py` (第24行, 第270行, 第306-310行)

**修改内容：**

1. **导入datetime模块** (第24行)
```python
from datetime import datetime
```

2. **修改配置** (第270行)
```python
# 修改前
'save_dir': 'baseline/results/bstgcn_50packets',

# 修改后
'save_dir_base': 'baseline/results/bstgcn_50packets',  # 基础目录
```

3. **创建时间戳目录** (第306-310行)
```python
# 创建带时间戳的保存目录
timestamp = datetime.now().strftime('%Y%m%d_%H%M%S')
save_dir = Path(config['save_dir_base']) / timestamp
save_dir.mkdir(parents=True, exist_ok=True)
config['save_dir'] = str(save_dir)  # 添加完整路径到配置中
```

4. **打印保存路径** (第318行)
```python
print(f"\n结果将保存到: {save_dir}\n")
```

**效果：**
- 每次运行创建独立的时间戳目录
- 例如：`baseline/results/bstgcn_50packets/20251120_184200/`
- 不会覆盖之前的结果
- 方便对比不同运行的结果
