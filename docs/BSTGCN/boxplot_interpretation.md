# 箱型图详细解释

## 📊 箱型图的组成部分

### 视觉结构：

```
     ○  ← 离群点（Outliers）
     │     异常值，远离主体数据
     │
     ┬  ← 上须（Upper Whisker）
     │     Q3 + 1.5×IQR 或最大非离群值
     │
 ┌───┐
 │   │  ← 箱顶（Q3）：75%分位数
 │   │     75%的数据小于此值
 │   │
 │━━━│  ← 中位数（Median）：50%分位数
 │   │     橙色线，50%的数据小于此值
 │   │
 │   │  ← 箱底（Q1）：25%分位数
 └───┘     25%的数据小于此值
     │
     ┴  ← 下须（Lower Whisker）
          Q1 - 1.5×IQR 或最小非离群值

IQR = Q3 - Q1（四分位距，箱体高度）
```
