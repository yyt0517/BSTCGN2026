## 💡 实用建议

### 1. 设置不确定性阈值

基于箱型图，可以设置不同的阈值策略：

#### 🔴 保守策略（阈值 = 0.70）
- **拒绝**：75%的错误预测
- **保留**：90%的正确预测
- **总拒绝率**：~15%
- **适用**：错误代价高的场景（医疗、金融）

#### 🟡 平衡策略（阈值 = 0.80）【推荐】
- **拒绝**：50%的错误预测
- **保留**：95%的正确预测
- **总拒绝率**：~8%
- **适用**：大多数实际应用（网络流量分类）

#### 🟢 激进策略（阈值 = 0.90）
- **拒绝**：25%的错误预测
- **保留**：98%的正确预测
- **总拒绝率**：~3%
- **适用**：需要高召回率的场景（实时系统）

### 2. 实现示例

```python
def predict_with_uncertainty(model, data, threshold=0.80):
    """
    使用不确定性阈值进行预测
    
    Args:
        model: BSTGCN模型
        data: 输入数据
        threshold: 不确定性阈值（默认0.80，平衡策略）
    
    Returns:
        reliable_preds: 可靠的预测结果
        review_samples: 需要人工审核的样本
    """
    predictions, uncertainties = model.predict(data)
    
    # 标记高不确定性样本
    reliable_mask = uncertainties <= threshold
    
    # 分离可靠预测和需要审核的样本
    reliable_preds = predictions[reliable_mask]
    review_samples = data[~reliable_mask]
    review_uncertainties = uncertainties[~reliable_mask]
    
    print(f"可靠预测: {len(reliable_preds)} ({len(reliable_preds)/len(data)*100:.1f}%)")
    print(f"需要审核: {len(review_samples)} ({len(review_samples)/len(data)*100:.1f}%)")
    
    return reliable_preds, review_samples, review_uncertainties
```
