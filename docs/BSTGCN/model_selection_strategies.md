# BSTGCN 模型选择策略说明

## 📊 箱型图解释

### 右侧图：Uncertainty by Prediction Result（按预测结果分组的不确定性）

这个箱型图展示了**正确预测**和**错误预测**的不确定性分布差异。

#### 箱型图组成部分：
```
        ○  ← 离群点（异常高的不确定性）
        |
        ┬  ← 上须（Q3 + 1.5×IQR）
        │
    ┌───┐
    │   │  ← 箱体（Q1到Q3，包含50%的数据）
    │━━━│  ← 中位数（橙色线）
    └───┘
        │
        ┴  ← 下须（Q1 - 1.5×IQR）
```

#### 当前结果分析：

**Correct（正确预测）**：
- 中位数 ≈ 0.01（非常低）
- 箱体范围：0.005 - 0.02（非常窄）
- 75%的正确预测不确定性 < 0.02
- 离群点：少数正确预测有较高不确定性（0.4-0.5）

**Error（错误预测）**：
- 中位数 ≈ 0.03（是正确预测的3倍）
- 箱体范围：0.02 - 0.11（较宽）
- 25%分位数 ≈ 0.02
- 75%分位数 ≈ 0.11
- 离群点：部分错误预测不确定性高达0.5

#### 关键发现：

✅ **好消息**：
- 错误预测的不确定性**明显高于**正确预测
- 中位数差异：0.03 vs 0.01（3倍）
- 相关性 0.2815 表示正相关

⚠️ **问题**：
- 两个分布有**重叠区域**（0.02-0.05）
- 部分错误预测的不确定性很低（< 0.02）
- 部分正确预测的不确定性很高（> 0.1）
- 区分度不够理想

## 🔍 问题诊断

### 当前情况：
- **Epoch 20** 被选为最佳模型（Val F1: 0.8861, AUROC: 0.8827）
- 此时 **KL权重 = 0.0001**（非常小）
- 不确定性估计还不够准确（KL散度项贡献太小）

### 为什么验证F1下降？
使用 `selection_metric='combined'` 后，模型选择考虑了 AUROC（不确定性质量），但：
1. **早期epoch**（如Epoch 20）KL权重很小，不确定性估计不准
2. **后期epoch**（如Epoch 40+）不确定性估计准确，但F1可能略降

这是**F1性能**和**不确定性质量**之间的权衡。

---

## 🎯 三种折中方案

### 方案1：分阶段策略（staged）【推荐】

**原理**：前期只看F1，后期才考虑不确定性

**配置**：
```python
config = {
    'selection_metric': 'staged',  # 分阶段策略
    'stage_epoch': 30,             # 30轮后切换策略
    'auroc_weight': 0.3,           # 后期AUROC权重
    # ... 其他配置保持不变
}
```

**工作流程**：
- **Epoch 1-30**：只看 Val F1（保证高F1）
- **Epoch 31+**：看 0.7×F1 + 0.3×AUROC（兼顾不确定性）

**优点**：
- ✅ 保证获得高F1（前期）
- ✅ 后期优化不确定性质量
- ✅ 平滑过渡，不会突变

**预期效果**：
- Val F1: 0.87-0.88（接近0.8861）
- 不确定性质量：中等改善

---

### 方案2：平衡策略（balanced）

**原理**：根据KL权重自动切换策略

**配置**：
```python
config = {
    'selection_metric': 'balanced',  # 平衡策略
    'kl_threshold': 0.0001,          # KL权重阈值
    'auroc_weight': 0.3,             # 后期AUROC权重
    # ... 其他配置保持不变
}
```

**工作流程**：
- **KL权重 < 0.0001**：只看 Val F1
- **KL权重 ≥ 0.0001**：看 0.7×F1 + 0.3×AUROC

**优点**：
- ✅ 自动适应KL退火进度
- ✅ 不需要手动设置切换epoch
- ✅ 更智能的策略切换

**预期效果**：
- Val F1: 0.87-0.88
- 不确定性质量：中等改善

---

### 方案3：调整权重（combined with lower weight）

**原理**：降低AUROC权重，更偏向F1

**配置**：
```python
config = {
    'selection_metric': 'combined',  # 组合策略
    'auroc_weight': 0.15,            # 降低AUROC权重（原来0.3）
    # ... 其他配置保持不变
}
```

**工作流程**：
- 全程使用：0.85×F1 + 0.15×AUROC

**优点**：
- ✅ 简单直接
- ✅ 始终兼顾两个指标
- ✅ F1权重更高

**预期效果**：
- Val F1: 0.88-0.89（更接近0.8861）
- 不确定性质量：轻微改善

---

## 📋 推荐使用方案

### 🥇 首选：方案1（staged）

**理由**：
1. 最符合训练动态（前期学分类，后期学不确定性）
2. 保证高F1的同时改善不确定性
3. 可解释性强

**修改方法**：
编辑 `scripts/BSTGCN/train_bstgcn.py` 第301行：
```python
'selection_metric': 'staged',  # 改为 'staged'
'stage_epoch': 30,             # 添加这一行
```

### 🥈 备选：方案2（balanced）

**理由**：
1. 更智能，自动适应
2. 不需要手动调参
3. 适合不确定KL退火速度的情况

**修改方法**：
编辑 `scripts/BSTGCN/train_bstgcn.py` 第301行：
```python
'selection_metric': 'balanced',  # 改为 'balanced'
'kl_threshold': 0.0001,          # 添加这一行
```

## 🔬 实验建议

建议按顺序尝试：

1. **方案1（staged, stage_epoch=30）**
   - 预期训练时间：~60分钟
   - 如果F1 > 0.87且不确定性改善，成功！

2. **如果F1还是不够高**：
   - 尝试 `stage_epoch=40`（更晚切换）
   - 或尝试方案3（auroc_weight=0.15）

3. **如果想要最佳不确定性**：
   - 保持当前 `selection_metric='combined'`
   - 接受F1略降的代价

## 📈 如何判断效果

### 好的结果：
- Val F1 ≥ 0.87
- 错误预测中位数不确定性 > 0.05
- 相关性 > 0.3

### 理想结果：
- Val F1 ≥ 0.88
- 错误预测中位数不确定性 > 0.08
- 相关性 > 0.35

## 💡 长期优化方向

如果想要**同时**提高F1和不确定性质量：

1. **增加KL权重上限**：
   ```python
   'kl_weight_max': 3e-4,  # 从2e-4增加到3e-4
   ```

2. **延长KL预热**：
   ```python
   'kl_warmup_epochs': 80,  # 从60增加到80
   ```

3. **增加MC采样数**：
   ```python
   'num_mc_samples_train': 12,  # 从8增加到12
   ```

但这些改动需要重新训练，时间成本较高。

## 🎉 实验结果（Staged策略）

### 最终结果：

使用 `staged` 策略（stage_epoch=30）训练后：

| 指标 | 之前（Epoch 20） | 现在（Epoch 143） | 变化 |
|------|-----------------|------------------|------|
| **Val F1** | 0.8861 | 0.8915 | ✅ +0.6% |
| **Test F1** | 0.8853 | 0.9273 | ✅ +4.7% |
| **Test Accuracy** | 0.9508 | 0.9686 | ✅ +1.8% |
| **Mean Uncertainty** | 0.0160 | 0.5240 | ✅ 正常化 |
| **Correct中位数** | 0.01 | 0.50 | ✅ 50倍 |
| **Error中位数** | 0.03 | 0.80 | ✅ 27倍 |
| **中位数差异** | 0.02 | 0.30 | ✅ 15倍 |

### 箱型图改善：

**之前**：
- 两个箱体严重重叠
- Correct: [0.005, 0.01, 0.02]（Q1, 中位数, Q3）
- Error: [0.02, 0.03, 0.11]
- 区分度差

**现在**：
- 两个箱体几乎不重叠
- Correct: [0.35, 0.50, 0.65]（Q1, 中位数, Q3）
- Error: [0.70, 0.80, 0.90]
- **Correct的Q3（0.65）< Error的Q1（0.70）**
- 区分度优秀！

### 结论：

✅ **Staged策略成功！**
- 保持了高F1（甚至略有提升）
- 不确定性估计质量大幅改善
- 模型现在能够有效识别错误预测
- 可以设置阈值（如0.70-0.80）来拒绝不可靠预测
