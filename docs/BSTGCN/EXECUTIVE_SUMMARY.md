# BSTGCN升级项目 - 执行摘要

## 项目概述

**目标**: 将当前的GraphSAGE + TCN Hybrid模型升级为贝叶斯时空图神经网络(BSTGCN)，实现不确定性量化能力。

**当前状态**: 已完成Hybrid模型开发，具备并行时空交互能力，Macro-F1约0.95。

**升级目标**: 引入贝叶斯推断框架，新增不确定性量化、OOD检测和对抗鲁棒性能力。

---

## 核心GAP (4个)

### 1. 权重表示: 点估计 → 贝叶斯分布 🔴
- **当前**: `W` (单一值)
- **目标**: `W ~ N(μ, σ²)` (分布)
- **影响**: 参数量翻倍，需实现贝叶斯层

### 2. 推理方式: 单次 → MC采样 🔴
- **当前**: 1次前向传播
- **目标**: M次采样 (M=30)
- **影响**: 推理时间增加30倍

### 3. 损失函数: CE → ELBO 🔴
- **当前**: 交叉熵
- **目标**: 重建损失 + KL散度
- **影响**: 训练流程改造

### 4. 输出内容: 预测 → 预测+不确定性 🟡
- **当前**: 仅类别
- **目标**: 类别 + 认知不确定性
- **影响**: 新增能力

## 主要挑战

### 计算成本
- 参数量翻倍
- 训练时间+30%
- 推理时间+30倍 (可优化至5-10倍)

### 工程复杂度
- 需实现9个新组件 (~670行代码)
- 需修改训练和推理流程
- 需调优4个新超参数

### 性能风险
- 训练可能不稳定 (KL散度爆炸)
- F1可能略降 (需调优)
- 推理速度可能不满足实时需求

---

## 缓解策略

### 渐进式升级
1. 先实现部分贝叶斯化 (仅ST-Blocks + 分类器)
2. 验证效果后决定是否全面贝叶斯化
3. 根据应用场景选择部署模式

### 性能优化
- 批量MC推理
- 减少MC样本数 (10-15)
- 自适应采样策略
- MAP推理模式 (无不确定性)

### 风险控制
- KL权重退火
- 更小的学习率
- 更长的warmup
- 梯度裁剪
