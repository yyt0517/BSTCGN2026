# 时空图神经网络 (STGNN) 设计方案

## 🎯 目标

设计一个能够超越LightGBM (Macro F1: 95.17%) 的时空图神经网络模型。

---

## 📊 数据特征分析

### 特征总览 (43个特征)

**9大特征组**：
1. **流量统计** (4): total_packets, total_bytes, packet_rate, byte_rate
2. **包大小** (4): avg/std/min/max_packet_size
3. **协议分布** (6): tcp/udp/icmp_packets, tcp/udp/icmp_ratio
4. **TCP标志** (6): syn/ack/fin/rst/psh_count, syn_ratio
5. **TCP窗口** (2): avg/std_tcp_window
6. **载荷** (3): total_payload_bytes, avg/std_payload_size
7. **TTL** (4): avg/std/min/max_ttl
8. **连接多样性** (4): unique_src/dst_ips, unique_src/dst_ports
9. **时间间隔** (4): avg/std/min/max_inter_arrival_time

### 攻击类型特征模式

| 攻击类型 | 主要协议 | 流量特征 | 连接特征 |
|---------|---------|---------|---------|
| **Benign** | TCP (41.4%) | 低流量 (9 pkt/s) | 低多样性 (2.5 IPs) |
| **HTTPFlood** | UDP (48.7%) | 高流量 (379 pkt/s) | 高端口多样性 (49 ports) |
| **ICMPFlood** | ICMP (25.8%) | 中流量 (177 pkt/s) | 中多样性 (5 IPs) |
| **SYNFlood** | TCP (32.1%) | 中流量 (130 pkt/s) | 低多样性 (4 IPs) |
| **SYNScan** | ICMP (36.2%) | 中流量 (141 pkt/s) | 高目标端口 (15 ports) |
| **SlowrateDoS** | UDP (50.1%) | 中流量 (158 pkt/s) | 低多样性 (4 IPs) |
| **TCPConnectScan** | ICMP (36.6%) | 中流量 (165 pkt/s) | 高源端口 (21 ports) |
| **UDPFlood** | UDP (63.2%) | **极高流量 (543 pkt/s)** | **极高源端口 (340 ports)** |
| **UDPScan** | UDP (68.3%) | 中流量 (156 pkt/s) | 高目标端口 (15 ports) |

### 关键发现

1. **LightGBM的优势**：
   - 能够捕捉特征之间的非线性交互
   - 对不同攻击类型的特征模式敏感
   - 特别擅长处理表格数据

2. **时序模型的劣势**：
   - 当前LSTM/GRU只使用了时序信息
   - 没有利用特征之间的关系
   - 没有捕捉不同特征组的交互模式

3. **GNN的机会**：
   - 构建特征之间的关系图
   - 捕捉特征组之间的交互
   - 结合时序信息和图结构信息

## 🏗️ 图结构设计

### 方案1: 特征组图 (Feature Group Graph)

**节点定义**：每个特征组作为一个节点 (9个节点)

```
节点1: 流量统计 (4维特征)
节点2: 包大小 (4维特征)
节点3: 协议分布 (6维特征)
节点4: TCP标志 (6维特征)
节点5: TCP窗口 (2维特征)
节点6: 载荷 (3维特征)
节点7: TTL (4维特征)
节点8: 连接多样性 (4维特征)
节点9: 时间间隔 (4维特征)
```

**边定义**：基于语义关系

```
流量统计 <-> 包大小 (流量由包大小决定)
流量统计 <-> 协议分布 (不同协议有不同流量模式)
流量统计 <-> 时间间隔 (流量与包到达间隔相关)
协议分布 <-> TCP标志 (TCP协议有标志位)
协议分布 <-> TCP窗口 (TCP协议有窗口)
包大小 <-> 载荷 (包大小包含载荷)
连接多样性 <-> 协议分布 (不同协议有不同连接模式)
TTL <-> 协议分布 (不同协议有不同TTL)
时间间隔 <-> 协议分布 (不同协议有不同时间模式)
```

**优势**：
- 节点数少，计算效率高
- 语义清晰，可解释性强
- 每个节点包含多维特征，信息丰富

**劣势**：
- 图结构较简单
- 可能丢失细粒度特征交互

---

### 方案2: 层次图 (Hierarchical Graph)

**三层结构**：

```
Layer 1 (原始特征层): 38个节点 (每个特征一个节点)
    ↓ 聚合
Layer 2 (特征组层): 9个节点 (每个特征组一个节点)
    ↓ 聚合
Layer 3 (全局层): 1个节点 (全局表示)
```

**边定义**：
- Layer 1内部：基于特征相关性 (Pearson > 0.5)
- Layer 1 -> Layer 2：特征到特征组的归属关系
- Layer 2内部：基于语义关系 (如方案1)
- Layer 2 -> Layer 3：所有特征组连接到全局节点

**优势**：
- 多尺度特征表示
- 保留细粒度和粗粒度信息
- 更强的表达能力

**劣势**：
- 计算复杂度高
- 需要更多训练数据

---

### 方案3: 动态图 (Dynamic Graph)

**节点定义**：每个时间步的特征组 (9个节点 × T个时间步)

**边定义**：
- **空间边**：同一时间步内的特征组之间 (如方案1)
- **时间边**：相邻时间步的同一特征组之间

```
时间步t-4:  [节点1] -- [节点2] -- ... -- [节点9]
              |          |                  |
时间步t-3:  [节点1] -- [节点2] -- ... -- [节点9]
              |          |                  |
时间步t-2:  [节点1] -- [节点2] -- ... -- [节点9]
              |          |                  |
时间步t-1:  [节点1] -- [节点2] -- ... -- [节点9]
              |          |                  |
时间步t:    [节点1] -- [节点2] -- ... -- [节点9]
```

**优势**：
- 同时捕捉时间和空间依赖
- 真正的时空图神经网络
- 能够学习攻击的演化模式

**劣势**：
- 图规模大 (9 × 5 = 45个节点)
- 计算复杂度高

## 🚀 推荐方案：混合时空图神经网络 (Hybrid STGNN)

### 架构设计

```
输入: (Batch, Time=5, Features=38)
    ↓
1. 特征分组层
    ↓
(Batch, Time=5, Groups=9, Group_Features=[4,4,6,6,2,3,4,4,4])
    ↓
2. 时间卷积层 (Temporal Convolution)
    - 对每个特征组独立进行时间卷积
    - 捕捉时间依赖
    ↓
(Batch, Time=5, Groups=9, Hidden_Dim=32)
    ↓
3. 图注意力层 (Graph Attention)
    - 对每个时间步构建特征组图
    - 使用GAT学习特征组之间的交互
    ↓
(Batch, Time=5, Groups=9, Hidden_Dim=32)
    ↓
4. 时序聚合层 (Temporal Aggregation)
    - 使用注意力机制聚合时间维度
    - 学习哪些时间步更重要
    ↓
(Batch, Groups=9, Hidden_Dim=32)
    ↓
5. 图池化层 (Graph Pooling)
    - 聚合所有特征组节点
    - 生成全局表示
    ↓
(Batch, Hidden_Dim=32)
    ↓
6. 分类层
    ↓
(Batch, Classes=9)
```

### 关键创新点

1. **特征组建模**：
   - 将38个特征分为9组
   - 每组内部特征语义相关
   - 减少图规模，提高效率

2. **时空解耦**：
   - 先用时间卷积捕捉时间依赖
   - 再用图注意力捕捉空间依赖
   - 避免时空耦合导致的复杂度爆炸

3. **注意力机制**：
   - 图注意力：学习特征组之间的重要性
   - 时序注意力：学习时间步的重要性
   - 自适应地关注关键信息

4. **多尺度融合**：
   - 特征组级别的表示
   - 全局级别的表示
   - 结合局部和全局信息

## 📐 图结构定义

### 邻接矩阵 (9×9)

基于语义关系定义：

```python
# 特征组索引
# 0: 流量统计, 1: 包大小, 2: 协议分布, 3: TCP标志, 4: TCP窗口
# 5: 载荷, 6: TTL, 7: 连接多样性, 8: 时间间隔

adjacency_matrix = [
    # 0  1  2  3  4  5  6  7  8
    [ 0, 1, 1, 0, 0, 1, 0, 1, 1],  # 0: 流量统计
    [ 1, 0, 1, 0, 0, 1, 0, 0, 0],  # 1: 包大小
    [ 1, 1, 0, 1, 1, 1, 1, 1, 1],  # 2: 协议分布 (中心节点)
    [ 0, 0, 1, 0, 1, 0, 0, 0, 0],  # 3: TCP标志
    [ 0, 0, 1, 1, 0, 0, 0, 0, 0],  # 4: TCP窗口
    [ 1, 1, 1, 0, 0, 0, 0, 0, 0],  # 5: 载荷
    [ 0, 0, 1, 0, 0, 0, 0, 0, 0],  # 6: TTL
    [ 1, 0, 1, 0, 0, 0, 0, 0, 0],  # 7: 连接多样性
    [ 1, 0, 1, 0, 0, 0, 0, 0, 0],  # 8: 时间间隔
]
```

**关键观察**：
- 协议分布是中心节点 (连接最多)
- TCP相关特征形成子图 (协议分布-TCP标志-TCP窗口)
- 流量统计连接多个节点 (流量是综合指标)

## 📊 预期性能提升

### 为什么能超越LightGBM？

1. **时序信息**：
   - LightGBM使用单点特征，丢失时序信息
   - STGNN使用5秒序列，捕捉攻击演化模式
   - 预期提升：+2-5%

2. **特征交互**：
   - LightGBM通过树分裂学习特征交互
   - STGNN通过图注意力显式建模特征关系
   - 预期提升：+1-3%

3. **多尺度表示**：
   - LightGBM是单尺度模型
   - STGNN有特征组级和全局级表示
   - 预期提升：+1-2%

4. **注意力机制**：
   - 自适应关注关键特征组和时间步
   - 对困难类别 (HTTPFlood, SlowrateDoS) 特别有效
   - 预期提升：+2-4%

**总预期提升**：+6-14%
**目标性能**：Macro F1 > 96% (vs LightGBM 95.17%)
