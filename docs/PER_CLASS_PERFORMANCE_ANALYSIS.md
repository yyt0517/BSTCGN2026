## 🔍 难点分析

### 为什么扫描类攻击较难检测？

**SYNScan (F1: 0.8567) 和 TCPConnectScan (F1: 0.8917)**

**原因分析**：

1. **与正常流量相似**
   - 扫描行为可能与正常连接尝试相似
   - 单个包特征不明显

2. **样本量较小**
   - SYNScan: 879样本
   - TCPConnectScan: 1,160样本
   - 相比洪泛攻击（8k-11k样本）少很多

3. **行为分散**
   - 扫描目标多个端口/IP
   - 50个包可能包含多个扫描目标
   - 模式不如洪泛攻击集中

**改进建议**：

1. **数据增强**
   - 对扫描类攻击进行过采样
   - 合成更多扫描样本

2. **特征工程**
   - 添加端口分布特征
   - 添加目标IP多样性特征

3. **模型改进**
   - 增强对分散模式的学习能力
   - 使用对比学习区分扫描和正常连接

## 💡 优势分析

### 为什么洪泛攻击检测如此优秀？

**HTTPFlood (0.9980), UDPFlood (0.9985), SYNFlood (0.9955)**

**原因分析**：

1. **特征明显**
   - 大量重复的同类型包
   - 时序模式规律

2. **样本充足**
   - HTTPFlood: 8,170样本
   - UDPFlood: 11,228样本
   - SYNFlood: 2,675样本

3. **包级图优势**
   - 50个包足够捕获洪泛模式
   - 时空交互（ST-Block）有效建模

4. **端到端优化**
   - 图构建与分类联合训练
   - 自动学习最优表示

### 为什么慢速攻击也能很好检测？

**SlowrateDoS (F1: 0.9944)**

**原因分析**：

1. **时序建模能力**
   - ST-Block的时间卷积（TCN）捕获长期依赖
   - Transformer捕获包之间的关系

2. **包级细粒度**
   - 50个包保留足够细节
   - 不像Burst图会聚合信息

3. **充足样本**
   - 3,237样本，足够学习模式
