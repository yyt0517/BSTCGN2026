# 5G-NIDD｜FDG/知识图谱 → GNN → BNN（不确定性）总体方案（总览）

> 目标：在维持既有**高准确率**的前提下，把 5G-NIDD 多分类做成**可解释 + 可置信**的检测系统。

---

## 一、研究目标与问题界定

**总体目标**

* 将你已构建的 **FDG（特征依赖图）/知识图谱** 引入学习流程，用图结构先验指导模型；
* 基于图神经网络（GNN）实现**多类别攻击识别**；
* 融入贝叶斯神经网络（BNN）或等价近似，输出**置信度/不确定性**，支撑**可信决策与可解释展示**。

**关键科学问题（RQs）**

1. **结构先验有效性**：FDG 中的关系（数学/协议/相关/跨层）是否能稳定提升或至少不损害分类性能，同时为解释提供结构依据？
2. **可置信推断**：BNN（或其近似）能否显著改善**概率校准**和**置信-风险权衡**（在保持精度的同时）？
3. **解释一致性**：由图结构与注意力得到的**路径/子图解释**，在同类样本与重训之间是否稳定、一致、可复核？

**预期贡献**

* 一套 **“FDG→GNN→BNN”** 的可复用方法论与实现范式；
* 同时产出**准确率基线、可信度（校准/选择性预测）、结构化解释**三类结果；
* 面向后续扩展（OOD/迁移）的通用接口与评测规范。

---

## 二、数据与知识图谱底座

**数据与标签**

* 数据集：5G-NIDD（多分类：良性 + 8类攻击，共9类）
* 总样本数：1,215,890条流记录
* 特征数：41个（从原始112个压缩而来）

**数据划分策略**

本项目采用两种数据划分方式，分别用于不同的实验目的：

### 方案1：随机分层划分（已完成）
* **位置**: `data/processed/v1_gnn_baseline/`
* **策略**: 按类别分层随机划分70%-15%-15%
* **优点**:
  - 训练/验证/测试集类别分布一致
  - 模型性能评估更稳定
  - 适合算法对比和消融实验
* **结果**:
  - 训练集: 851,123样本 (70.0%)
  - 验证集: 182,383样本 (15.0%)
  - 测试集: 182,384样本 (15.0%)
  - 测试集准确率: **99.994%**, Macro-F1: **99.949%**

### 方案2：基于时间划分（新增）⭐
* **位置**: `data/processed/time_divided/`
* **策略**: 对每个攻击类型分别按时间排序后划分70%-15%-15%
* **优点**:
  - 更符合真实场景（用历史数据预测未来）
  - 避免同一攻击事件的样本分散到不同集合
  - 评估模型的时间泛化能力
  - 防止数据泄露（测试集样本时间晚于训练集）
* **结果**:
  - 训练集: 851,119样本 (70.0%)
  - 验证集: 182,379样本 (15.0%)
  - 测试集: 182,392样本 (15.0%)
  - 所有集合均包含全部9个类别
* **时间范围示例**:
  - Benign: 训练集0.0-25.2分钟, 验证集25.2-47.2分钟, 测试集47.2-60.0分钟
  - HTTPFlood: 训练集28.6-43.1分钟, 验证集43.1-44.3分钟, 测试集44.3-45.9分钟
  - UDPFlood: 训练集0.0-58.4分钟, 验证集58.4-58.6分钟, 测试集58.6-60.0分钟

**划分方式对比**

| 维度 | 随机分层划分 | 基于时间划分 |
|------|-------------|-------------|
| **数据泄露风险** | 中等（同一攻击事件可能分散） | 低（严格时间顺序） |
| **真实场景符合度** | 中等 | 高（模拟实际部署） |
| **类别平衡性** | 优秀（完全一致） | 良好（都包含所有类别） |
| **模型性能** | 通常较高 | 通常较低（更具挑战性） |
| **适用场景** | 算法对比、消融实验 | 实际部署评估、泛化能力测试 |

**FDG/知识图谱**

* 节点：以**特征**为节点（可带类型/范畴信息）。
* 边与语义：包含**数学恒等、统计相关、协议/状态约束、跨层弱关系**等；边可带权重与**条件化 gate**（按样本条件激活）。
* 使用原则：

  * **不向测试泄露**：FDG 的统计构建限定在训练范围（或采用既定版本并在附录核验）；
  * **简洁稳定优先**：先采用核心、连通、质量可控的图版本，后续再逐步细化。

## 三、模型与训练设计

**总体流水线**

1. **样本图实例化**：每个样本在 FDG 上“点亮”其节点特征；根据样本协议/时长/状态对**条件边**进行 gate；边权作为结构先验输入。
2. **GNN 表征学习**：采用**关系感知的 GNN**（如 R-GAT/GATv2/异质GNN），在图上进行消息传递与聚合，得到样本级表示并完成多分类。
3. **BNN/不确定性**：在训练或推理阶段引入贝叶斯化（任选其一或渐进叠加）：

   * **MC Dropout**（推理多次采样）；
   * **变分/贝叶斯层**（对部分层进行参数后验近似）；
   * **深度集成/后验近似**（如 SWAG/小规模集成）。
     输出：**预测分布均值 + 方差/熵** 等不确定性量化。
建议采用渐进式策略：

先实现MC Dropout（实现简单，效果稳定）
再尝试变分贝叶斯层（更精确的不确定性估计）
最后考虑深度集成（计算成本较高但效果最好
4. **解释生成**：基于注意力/消息权重与图结构，生成**路径级解释**、**边类型贡献概览**与**置信图谱**（将不确定性叠加到解释子图上）。

**训练要点（原则级）**

* 优先确保**稳定收敛与可复现**（固定分割与种子、记录版本）；
* 类不均衡用**分层采样/损失重权**等轻量策略；
* 先完成**非贝叶斯版**收敛与解释可视化，再引入**单一贝叶斯近似**，最后再对比多种近似。

## 四、实验设计与评测指标

**基线与对照（简约）**

* **传统强基线**（已实现，位于`baseline/`目录）：
  - Random Forest (RF)
  - Decision Tree (DT)
  - K-Nearest Neighbors (KNN)
  - Support Vector Machine (SVM)
  - Multi-Layer Perceptron (MLP)
  - XGBoost
  - LightGBM

  **数据集**: 使用`data/processed/time_divided/`（基于时间划分）

* **结构消融**：

  * 无图/仅自环（验证“图结构”的必要性）；
  * 无边权/无条件 gate（验证“先验注入”的贡献）；
* **BNN 消融**：非贝叶斯 vs. 单一近似（MC Dropout）vs. 备用近似（变分/集成）。

**评测维度**

1. **分类性能**：Accuracy、micro-F1、macro-F1、混淆矩阵（关注小众类别）。
2. **可信度与校准**：ECE、NLL、Brier Score、**可靠性曲线**；

   * **选择性预测**（Risk-Coverage/拒判曲线）：用不确定性阈值换取更高的可信精度。
3. **解释性**：

   * 样本级：Top-k 路径/子图（节点、边、类型、权重）；
   * 数据集级：边类型贡献分布、解释稳定性（重训一致性/近邻一致性）。
4. **效率记录**：训练/推理时延、显存占用（报告方法成本）。

**结果呈现**

* **三张主表**：分类性能、可信度（校准/选择性）、解释稳定性；
* **两类图版**：可靠性曲线 & 置信-覆盖曲线；“置信图谱”与典型案例路径可视化。

---

> **一句话总结**：
> 以 **FDG/知识图谱** 把领域先验装进**图结构**，用 **GNN** 学习结构化表征，再用 **BNN** 输出**置信度**与**校准良好**的概率，让高精度的 5G-NIDD 多分类**既能解释“为什么”，又能量化“有多确信”**。
